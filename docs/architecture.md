# 架构

React 负责概览、版本、环境、设置和任务详情。Tauri 自定义命令连接 Rust，前端只提交安装实例标识、目标版本和经过定义的业务参数。

Rust 的安装检测提供来源证据与实际路径。更新计划捕获当前安装状态，执行前再次核对。任务由后台持有，界面通过事件与快照重连。Native、npm 和 WinGet 使用各自的执行方式，执行后复核版本和 Shell 命中项。

平台与存储模块负责 HKCU PATH 原始值、配置字段合并、变更台账、代理凭据、schema 保护及原子持久化。操作恢复根据实际磁盘和进程状态判断。

完整消息结构见 [IPC 契约](IPC_CONTRACT.md)。产品行为与验收项目见 [实施方案](../PROJECT_PLAN.md)。
