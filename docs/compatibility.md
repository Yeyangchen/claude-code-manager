## 已知边界

- 系统代理支持代理环境变量与 Windows 显式代理。PAC 脚本解析尚未实现，可手动填写代理 URL。
- Shell / 项目配置的检测限于当前用户及可读取范围。其他终端中临时定义的函数、远程组织策略和其他项目的有效配置需要在相应环境中用官方诊断核实。
- 管理器退出不等于安装器撤销。遇到中断需重新检测实际版本，不自动删除未知安装文件。
- 稳定版本发布以首发验收矩阵完成为门槛，预览版不替代验收。

## 网络来源

正常版本检查及下载安装会访问下列来源；没有统计上报端点。

| 来源 | 用途 |
| --- | --- |
| `downloads.claude.ai` | 官方通道、manifest、签名、二进制文件 |
| `claude.ai` | 官方安装入口与文档跳转 |
| `code.claude.com` | 官方使用说明 |
| `raw.githubusercontent.com` | Anthropic 公开 CHANGELOG |
| `api.github.com`、`github.com` 及 GitHub Release CDN | 管理器发布与更新 |
| npm / WinGet 配置的源 | 用户明确执行相应来源的安装操作 |
| Microsoft WebView2 下载域名 | 安装器补充 WebView2 运行时 |

第三方安装器可能访问其自身官方 CDN，系统代理也可能改变实际连接路径。A36 抓包完成后进一步收紧并记录实际域名。
